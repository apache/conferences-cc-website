1) The xalan.pdf is the notes for the presentation

2) The xalan.ppt is the presentation

3) To make the examples work download the latest version of xalan-java. I renamed the folder to be c:\xalan to make the examples work. 
	
	- http:\\xml.apache.org

4) The xslt_files folder contains all xslt style sheets.

5) The xml_Files folder contains the xml file used in all the demos.

6) The java folder contains a simple XSLT processor. It works the same as the xalan.bat for the most part.

7) The xalan.bat is a simple batch file that will transform a incoming xml to a outgoing xml using a specified xslt style sheet.

	You need to pass four variables to xalan.bat:

	- Xalan debugging option
	- incoming xml
	- xslt style sheet
	- outgoing xml file that you want the result tree to be printed to.
